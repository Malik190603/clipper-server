# Clipper Server

Server untuk clipper-ku.pages.dev: mengambil potongan video YouTube (yt-dlp + ffmpeg).

Environment variables:
- APP_TOKEN: kunci bebas buatanmu, diisi juga di website.
- YT_COOKIES (opsional): isi cookies.txt (format Netscape) dari akun YouTube cadangan, dipakai bila YouTube memblokir server.
